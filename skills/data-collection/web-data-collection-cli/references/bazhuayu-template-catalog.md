## 费用分类说明

所有模板的 CLI 参数均为 `parameters: []`（关键词/URL 内置在模板 XML 中，不可通过 CLI 参数修改）。需通过编辑任务文件的 NavigateAction URL 或 EnterTextAction 文本来改变关键词。

| 类型 | 命名特征 | 本地运行 | 云运行 | 说明 |
|------|---------|---------|-------|------|
| **轻量免费版** | 名称含"轻量免费版"或"简易免费版" | 免费 | 免费或低价 | 功能简化，数据量有限 |
| **普通版** | 无特殊标记 | 免费 | 消耗积分 | 功能完整，本地跑免费 |
| **限云采集** | 名称含"限云采集" | 不支持 | 消耗积分 | 必须云端跑，消耗积分 |
| **限本地** | 名称含"限本地" | 免费 | 不支持 | 仅限本地运行 |

- 当前账户：免费版，余额 12 积分，云任务上限 100 个
- 普通模板和轻量版本地运行免费；云端运行消耗积分
- 限云采集模板必须云端运行，消耗积分
- 云任务达上限时，`detect` 仍会写入本地文件，用 `bazhuayu run <name> --task-file <path.json>` 绕过云 API
