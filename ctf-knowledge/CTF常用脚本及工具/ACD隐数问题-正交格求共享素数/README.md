# ACD 隐数问题求共享素数 + gcd(e,φ)≠1 RSA 开根

## 适用特征
- 多组 l_i = q_i·P + r_i，共享同一素数 P（各 q_i、r_i 独立随机）
- P 可从多组 l_i 的 gcd 类技巧恢复（Approximate Common Divisor）
- 后接 RSA 且 gcd(e, φ)≠1（e 为合成数且因子来自 e1·e2 拼接）

## 位宽与参数预测（关键）
设 l 有 B_l 位、q 有 B_q 位、r 有 B_r 位、P 有 B_p 位，组数 m：
- 正交格权重 C 必须 > |l|：C = 2^(B_l + 4) 量级。C 太小 → LLL 给出假正交向量（u·l ≈ 2^(B_l-|u|) 非零）
- 期望最短正交向量 |u| ≈ 2^(B_l - B_p)（本题 1536-512=1024/√30≈2^53 吻合）
- 可用性判据：|u|·√m·2^B_r < 2^B_p 才能保证 u·q = u·r = 0；筛出 m-2 个后剩 2 维核
- 组数需求：正交格维数 = m，需 m-2 ≥ 2 即可，m=30 非常充裕；m=4~5 也可解

## 三步法
1. **正交格**：30×(31) 基，行 = [C·l_i | e_i]，LLL 后取首列为 0 的行 → U（m-2 个正交向量）
2. **饱和整核**：对 U 转置做整数欧几里得行约减（跟踪幺模变换 R），末 2 行 = ker_Z(U) = span_Z(q, r)
   - 坑：sympy nullspace 是非饱和子格（有理基通分后含大指数），Gauss 组合枚举永远不会命中 ±r
   - Gauss 归约后短向量 = ±r（r 比任意非核组合短得多）
3. **恢复 P**：P = gcd(l_i − r_i)（多取几组验证）；注意 P∤r_i，必须精确 ±r，gcd 差一倍即失败

## gcd(e, φ)≠1 开根（sympy 超时时的纯群论方案）
- g = gcd(e, φ)，先 c1 = c^(（e/g)⁻¹ mod φ) 得 c1 = m^g
- 对 g 的每个素因子 k 逐层开根（本题 7×191）：
  - v_k(p−1)=1：x0 = c^(k⁻¹ mod s)（s = (p−1)/k），乘 μ_k 单位根枚举全部根
  - v_k(p−1)=2（如 49 | p−1）：先 y0 = c^(k⁻¹ mod m)（m 为 k-free 部分），y0^7 = c·w 会差一个 μ_k 校正项 w，用 k² 阶元素 ζ 定位 w 在 μ_k 中的离散指数后校正（7i ≡ −d_cor mod k²）
  - k ∤ p−1：x ↦ x^k 是双射，直接指数逆还原
- **全部 g₁·g₂ 个 CRT 组合都满足 m^e ≡ c**！唯一区分手段是明文可读性筛选（ASCII 占比 / flag 格式）
- sympy nthroot_mod 在 512 位素数 + 合成大指数上会走离散对数路径彻底超时，不要用

## Sylow 分量法开根（替代实现）与候选筛选坑
- 更稳的全根实现：对每个 r^k || p−1 的 Sylow 分量做查表 DLP（s 分量唯一解 + Sylow 子群内解指数逆），免 μ_k 手工校正，任意重数通用，根数 = gcd(e, p−1)。脚本：`../RSA_e与phi不互素多根-Sylow分量法.py`（2026-09-06 验证）
- 候选过滤坑：`m >> (bit_length−48)` 取前几字节判可打印，隐含假设首字节 ≥ 0x80；首字节是 ASCII（如 DASCTF 的 'D'=0x44）时窗口错位 1bit，切出的字节含高位垃圾，真 flag 被误杀。正确姿势：候选多时按「最长可打印前缀」排序取最优，勿逐字节硬过滤。
